# SetWatch current status — 7 September 2026

This is the current handoff point for the Agentic Cinema / Parallel-track submission.

## Verified in repository

- Repository is public.
- Runtime uses Google ADK / Gemini and Parallel Search.
- Every live run performs a mandatory Parallel Search before Gemini evaluation.
- Default Parallel search mode is `fast`.
- Live runs refuse to proceed without `PARALLEL_API_KEY`.
- Demo mode is explicit and labelled; it is not a silent fallback for live runs.
- Runtime records partner traces and Parallel search IDs.
- Model-cited sources are constrained to URLs returned by captured Parallel evidence; unsupported citations degrade the finding to VERIFY.
- UI exposes LIVE/DEMO runtime state, GO / VERIFY / CHANGE findings, evidence/inference/consequence/action, sources, partner-call count and search IDs.
- README, Cloud Run deployment instructions, live smoke-test gate, CI and submission copy are present.
- `docs/SUBMISSION.md` contains the current Devpost copy and demo-video sequence.

## No further architecture work required before final qualification

Do not add features unless a real judging or reliability failure is observed. The remaining work is qualification and packaging, not product redesign.
